# Калькулятор сплиттеров

## Что внутри

- React + Vite приложение для расчета и визуализации сплиттеров.
- `vite-plugin-singlefile` собирает проект в один автономный HTML-файл.
- Playwright-тесты уже включены.

## Как запустить на другом компьютере

1. Установить Node.js 20+.
2. Скопировать весь проект на новый компьютер.
3. Открыть папку проекта в терминале.
4. Выполнить:

```bash
npm install
npm run dev
```

После этого приложение откроется по адресу `http://127.0.0.1:5173/`.

## Как собрать для переноса

Если нужен готовый автономный файл без запуска dev-сервера:

```bash
npm install
npm run build
```

После сборки готовый файл будет в `dist/index.html`. Его можно открыть напрямую в браузере или перенести вместе с другими файлами проекта.

## Удобные скрипты для Windows

- `run.bat` - запускает dev-сервер.
- `build.bat` - собирает автономную версию и открывает `dist/index.html`.
